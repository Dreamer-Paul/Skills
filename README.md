# Skills

保罗公开的 Agent Skills。每个 Skill 是 `skills/<name>/SKILL.md`。

```text
skills/
└── frontend-conventions/
    └── SKILL.md
```

安装全部：

```bash
npx skills add Dreamer-Paul/Skills
```

只安装一个：

```bash
npx skills add Dreamer-Paul/Skills@frontend-conventions -g -y
```

发布前可先列出仓库里能被发现的 skill，这一步不会安装：

```bash
npx skills add Dreamer-Paul/skills --list
```
